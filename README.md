# SIFSM — Sistema Integrado de Futuro Sustentável em Marte (Aurora Siger)

Protótipo desenvolvido para a Fase 7 do projeto integrador da FIAP, focado na gestão energética, automação lógica, persistência de dados e simulação computacional da colônia marciana **Aurora Siger**.

---

## 📂 Estrutura de Arquivos da Entrega (.zip)

O pacote compactado de entrega contém os seguintes arquivos obrigatórios:
- `codigo_fonte.py` — Script principal em Python contendo o menu interativo, CRUD e chamadas de módulos.
- `script_banco.sql` — Script SQL para a criação e estruturação do banco de dados relacional.
- `dados_aurora_siger.csv` — Base de dados simulada para consultas e análises complementares.
- `circuito_logico.png` — Imagem detalhada do circuito lógico digital, portas lógicas e tabela-verdade.
- `simulacao_computacional.py` — Módulo responsável pelas simulações estocásticas e dinâmicas da bateria.
- `relatorio_tecnico.md` — Relatório técnico completo documentando a fundamentação teórica e arquitetural do projeto.
- `README.md` — Instruções de instalação, dependências e execução do sistema.
- `link_video.txt` — Arquivo contendo o link do YouTube da apresentação gravada (vídeo não listado, máximo 5 minutos).

---

## ⚙️ Requisitos do Sistema
- **Python 3.x** instalado no ambiente de execução.
- Bibliotecas padrão do Python (o projeto foi construído utilizando bibliotecas nativas como `sqlite3` e `collections`, garantindo alta portabilidade sem dependências complexas externas).

---

## 🚀 Como Executar o Projeto

1. Certifique-se de que todos os arquivos do projeto encontram-se descompactados na mesma pasta.
2. Abra o terminal de comando (ou o **Visual Studio Code**) na pasta raiz do projeto.
3. Execute o script principal digitando o comando:
   ```bash
   python codigo_fonte.py
   ```
4. Navegue pelo menu interativo exibido no terminal para testar as operações de CRUD, avaliar as regras booleanas, consultar a fila de alertas, rodar simulações computacionais e verificar o modelo linear preditivo.
